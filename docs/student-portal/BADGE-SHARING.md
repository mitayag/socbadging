# Student Badge Sharing

## My Badges

Students can open **My Badges** from the Student Portal to browse credentials issued to their student record. Cards show:

- Badge name and description
- Issuer
- Class
- Issued date
- Expiry date
- Current status: Active, Expired, or Revoked

Only the authenticated student’s own records are returned. Another student’s credential ID resolves as not found.

## Badge details

The credential detail page shows:

- Immutable badge and issuer information
- Issuance and expiry dates
- Current lifecycle status
- Criteria and skills
- Cryptographic verification result
- Signed JSON-LD, badge image, and PDF downloads
- A public verification link
- Social sharing and QR code sharing

## Downloads

- **View JSON-LD** opens the machine-readable credential.
- **Download JSON-LD** downloads the signed credential.
- **Download Badge Image** downloads the badge artwork.
- **Download PDF Summary** downloads a human-readable summary with a QR code.

The signed JSON-LD is authoritative. The PDF is a summary.

## Sharing

Students can:

- Copy the public verification link.
- Use native sharing when supported by the browser.
- Share to LinkedIn or Facebook.
- Share by email.
- Download or scan a QR code for the public verification page.

The public verification page does not display the student’s email address or private student number. It uses a privacy-safe recipient display name.

## Revoked and expired credentials

Revoked and expired credentials remain visible with their status. Public verification clearly displays the revoked or expired state. Revocation history is preserved; sharing links do not make a revoked credential appear active.

## Privacy

Do not share private student information or internal identifiers. Share only the public verification link or downloaded public credential. If a credential is revoked, stop sharing it and use the public verification page to show current status.
